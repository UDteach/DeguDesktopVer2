DeguDesktopVer2 0.2.1

画面下で暮らすデグーのデスクトップアプリです。

- 散歩・ひと休み・ときどき短いダッシュ。
- 10の毛色、1〜10匹、個別の名前、4段階の大きさ。
- お顔くしくし・立ち上がり・回し車は全10色。足ぴーんはアグーチのみ。
- くしくしの体の大きさ・足元を統一。回し車の車輪・頭・胴体・尾は固定して、足を動かします。
- 表示モニター、歩く範囲、上下位置、停止・非表示を設定。変更は自動保存。
- 動物の表示はマウス入力を背後に通し、作業中のフォーカスを奪いません。

Windows x64: インストーラーEXE / ZIP。Mac（macOS 13以降）: Apple Silicon / IntelそれぞれDMG / ZIP。
開発者証明書によるコード署名とApple公証はありません。Macはアドホック署名のみです。

開き方、更新、削除: https://udteach.github.io/DeguDesktopVer2/download.html
各ファイルのSHA-256は添付のSHA256SUMS.txtで確認できます。

回し車の出入りはフェードです。ジャンプの制作から採用した素材は立ち上がりとして収録しています。動作時間や頻度には演出上の調整があります。
Macの実機での複数画面・スリープ復帰・初回のセキュリティ確認は、環境ごとの確認が必要です。
